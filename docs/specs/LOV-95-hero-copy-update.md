# LOV-95 Hero 문구 변경 스펙

## 문제 정의
현재 홈 히어로 헤드라인("사랑과 비주얼의 교차점에서")이 회사명 의미를 과하게 전면에 내세워, 방문자가 즉시 이해해야 할 가치 제안(무엇을 해주는 회사인가) 전달을 약화시킨다. 지금 단계에서는 브랜드 어원 설명보다 서비스 가치 전달 우선순위가 높다.

## Goal / Non-goal
- Goal: 첫 화면 헤드라인을 "고객이 즉시 이해하는 가치 제안" 중심으로 교체한다.
- Goal: 기존 톤(신뢰, 전문성)은 유지하되 해석 부담을 줄인다.
- Non-goal: 전체 브랜드 리브랜딩, 섹션 구조 변경, 신규 기능 추가.
- Non-goal: Footer 브랜드 태그라인 전면 교체(이번 이슈 범위 제외).

## 대상 사용자 / 시나리오
- 대상: 처음 방문한 잠재 고객(대표/실무자), 3초 이내에 회사 정체성을 파악하려는 사용자.
- 시나리오: 랜딩 직후 Hero 문구를 읽고 "무슨 회사인지"를 바로 이해하고 다음 행동(스크롤/문의)으로 이어진다.

## 사용자 흐름
1. 사용자가 홈에 진입한다.
2. Hero H1에서 회사가 제공하는 가치(IT 솔루션 파트너십)를 즉시 이해한다.
3. 보조 문구(P)에서 신뢰/협업 맥락을 확인한다.
4. CTA("문의하기", "더 알아보기") 중 하나를 선택한다.

### 오류/엣지 상태
1. 문구 길이 증가로 모바일에서 3줄 이상 과도 줄바꿈이 생기면 실패로 간주한다.
2. 기존 디자인 대비 대비비가 낮아 가독성이 떨어지면 실패로 간주한다.
3. 카피 후보 간 합의가 없을 경우, CEO 승인된 단일 문구만 반영한다(임의 병합 금지).

## 카피 방향(결정)
- 기존(교체 대상):
  - 사랑과 비주얼의 교차점에서,
  - 비즈니스를 새롭게 디자인합니다
- 변경(기본안):
  - 비즈니스 성장을 위한
  - IT 솔루션 파트너

## 수용 기준 (Acceptance Criteria)
- Hero H1 텍스트가 위 "변경(기본안)" 2줄로 반영되어야 한다.
- 모바일(360px), 태블릿(768px), 데스크톱(1280px)에서 H1이 시각적으로 깨지지 않아야 한다.
- 기존 CTA 링크 동작(`#contact`, `#about`)에 변경이 없어야 한다.
- Hero 하위 설명 문구(`Lovizu는 ...`)는 이번 이슈에서 변경하지 않는다.
- 회귀: 레이아웃 shift(눈에 띄는 줄바꿈 점프)가 없어야 한다.

## 성공 지표 (Outcome over output)
- 1차 지표: Hero 구간 이탈률(첫 스크롤 전 이탈) 10% 상대 개선.
- 측정 가정: 배포 후 7일간 기존 대비 비교(동일 유입 채널 기준).

## 우선순위 근거 (RICE 간이)
- Reach: 높음(홈 방문자 전원)
- Impact: 중간~높음(첫 인상/가치 이해)
- Confidence: 중간(정량 검증 필요)
- Effort: 낮음(텍스트 교체 + QA)

## 오픈 이슈 / 가정
- 가정: 현재 문제는 의미 과밀에서 발생하며, 간결한 가치 제안으로 개선된다.
- 오픈: 배포 후 성과가 미미하면 Hero 보조문구까지 2차 실험 대상으로 확장 검토.

## 범위 추정
- S (0.5~1일)

## 시간 압박 시 컷 제안 (MVP / Scope creep alarm)
1. 컷 1: 카피 A/B 실험 제거, 단일 카피 즉시 반영.
2. 컷 2: Footer 문구 검토 제외(현 이슈 범위 유지).
3. 컷 3: 추가 애니메이션/스타일 튜닝 제외.
