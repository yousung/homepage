- Primary buyer: 10-50명 규모 SaaS/커머스 팀의 실무 리드(PO, PM, 초기 제품 오너)
- Secondary audience: 문제 정의와 실행력을 중시하는 초기 커리어 프론트엔드/풀스택 지원자

- "아이디어를 운영 가능한 제품으로 바꾸는, 실행 중심 IT 파트너"

## Channel Focus (Initial)
- Landing page first: 구매 의도/채용 관심 모두가 반드시 통과하는 고의도 채널
- LinkedIn founder post second: B2B 신뢰 형성 채널, 메시지 재사용 효율이 높음
- Ignore for now: 단기 소셜 다채널 동시 운영(X, 인스타) — 초기 리소스 분산 대비 전환 추적이 약함

## Success Metric & Kill Criteria
- Success metric (2주): 랜딩 Contact 제출 전환율 `>= 2.5%` (세션 대비 제출)
- Secondary metric: Hero CTA 클릭률 `>= 12%`
- Kill criteria (2주): Contact 전환율 `< 1.0%` 이면 메시지 전면 교체 및 채널 확장 중단

## Lens Check (Traceable)
- Jobs-to-Be-Done: "아이디어를 빠르게 운영 가능한 제품으로 전환"
- Value proposition canvas: pain(실행 리소스 부족) -> gain(빠른 실행안/개선 루프) -> fit(구축+개선 동반)
- One-message-per-asset: 랜딩의 1차 목표를 "문의 제출"로 고정
- Honest claims: 출시일/미구현 기능/정량 성과 약속 없음
